# CineVox — Seaway Suez

نظام **حجز سينما** كامل مستوحى من VOX Cinemas — بواجهة **عربي وإنجليزي**:

1. تصفح **كتالوج الأفلام** مع البحث والفلترة (نوع الفيلم، حالة العرض).
2. اختار **العرض المناسب** من مواعيد العرض لكل فيلم.
3. احجز كراسيك من **خريطة المقاعد التفاعلية** — الكراسي المحجوزة بتظهر فورًا ومفيش حجز مكرر لنفس الكرسي.
4. لوحة تحكم للأدمن: إحصائيات وإيرادات، وإدارة كاملة للأفلام والعروض.

**المطور: Hussein Ali**

---

## المميزات

- **واجهة عربي/إنجليزي** (React + Tailwind) مع تبديل لغة.
- **كتالوج أفلام** بالبحث والفلترة، صفحة تفاصيل لكل فيلم بمواعيد العرض.
- **حجز كراسي** بخريطة مقاعد تفاعلية مع كشف تعارض الحجوزات.
- **تسجيل ودخول** بحسابات مستخدمين (JWT + bcrypt).
- **لوحة أدمن**: إحصائيات وإيرادات + إضافة/تعديل/حذف أفلام.
- **تسعيرة ثابتة**: 100 جنيه للكرسي + 50 مصاريف خدمة.
- قاعدة بيانات JSON بسيطة على القرص — من غير أي إعداد خارجي، والبيانات التجريبية بتتزرع تلقائيًا عند أول تشغيل.

## التشغيل محليًا

### ويندوز (الأسهل)

ادبل كليك على `start.bat` — هيشغّل السيرفر على `http://localhost:3001` والواجهة على `http://localhost:5173`.

### يدويًا

```bash
# أول مرة فقط — تثبيت الاعتماديات
cd server && npm install
cd ../client && npm install

# شغّل السيرفر (Terminal واحد)
cd server && npm start

# وشغّل الواجهة (Terminal تاني)
cd client && npm run dev
```

افتح `http://localhost:5173`.

## حساب الأدمن

| الدور | اسم المستخدم | كلمة السر |
|------|--------------|-----------|
| أدمن | Seaway_Admin | seawaysuez |

> سجّل الدخول باسم المستخدم ده وهتتفتحلك لوحة الأدمن علطول. باقي المستخدمين بيعملوا حساب جديد من صفحة التسجيل.
> عايز ترجّع البيانات التجريبية من الأول؟ شغّل `npm run seed` جوه فولدر `server`.

## البنية

```
client/                         # الواجهة — React 18 + Vite + Tailwind
├── src/pages/                  # Home, Movies, MovieDetails, Booking, Login, Register, Profile, Admin
└── src/components/             # SeatMap, Navbar, MovieCard, Footer...
server/                         # الـ API — Express
├── index.js                    # نقطة التشغيل
├── routes/                     # auth, movies, bookings, admin
├── db.js                       # قراءة/كتابة db.json
└── seed.js                     # البيانات التجريبية (أفلام + عروض + مستخدمين)
start.bat / start.sh            # تشغيل السيرفر + الواجهة مع بعض
```

البيانات بتتخزن في `server/data/db.json` (مش محتاجة داتابيز خارجية).

## الـ API

| Method | Path | الوصف |
|--------|------|-------|
| `GET` | `/api/health` | فحص حالة السيرفر |
| `POST` | `/api/auth/register` | إنشاء حساب |
| `POST` | `/api/auth/login` | تسجيل دخول (بيرجع JWT) |
| `GET` | `/api/movies` | قائمة الأفلام + بحث وفلترة (`q`, `genre`, `status`) |
| `GET` | `/api/showtimes/:id` | تفاصيل عرض معين |
| `GET/POST` | `/api/bookings` | حجوزات المستخدم + إنشاء حجز (مع كشف تعارض الكراسي) |
| `GET` | `/api/admin/stats` | إحصائيات وإيرادات (للأدمن فقط) |
| CRUD | `/api/admin/movies` | إدارة الأفلام (للأدمن فقط) |
